# Wind project financial model
This brand folder contains the cost estimation of one-year wind measurement campaigns and the financial model of the 120 MW onshore wind farm.
It supports the techno‑economic comparison of 4 different wind‑measurement strategies by linking uncertainty in energy yield to project finance outcomes (net present value, and levelized cost of electricity).
The model quantifies capital expenditure, operational expenditure, debt capacity based on P90 values, and yearly cash flow. 

## Content: 
- Cost and financial model.xlsx

The Excel file includes detailed cost assumptions for LiDAR‑based and UAV‑based wind‑measurement campaigns, P90 values of four scenarios, project finance parameters, and yearly discounted cash‑flow calculations.
