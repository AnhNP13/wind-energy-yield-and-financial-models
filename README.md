# General information
This repository contains two complementary modelling components developed for a techno‑economic assessment of a hypothetical 120 MW onshore wind farm in a mountainous area. 
The first component (wind-energy-yield-model) simulates wind‑energy yield under different measurement strategies using a Monte Carlo uncertainty‑propagation engine.
The second component (wind-project-financial model) evaluates project‑finance outcomes, including debt capacity, net present value, and levelized cost of electricity, based on the resulting energy‑yield distributions.

#Purpose
The combined framework enables a transparent comparison of LiDAR‑based and UAV‑based wind‑measurement campaigns and their impact on project bankability.
